# Запуск CRM на сервере (VPS)

После установки CRM работает в интернете по адресу вида `https://crm.lunagarden.kg`. Все сотрудники открывают её
с телефона или компьютера. Https включается сам: бесплатный сертификат Let's Encrypt выпускается и продлевается
автоматически. Без https не работают камера в киоске отметок (Face ID) и подключение WhatsApp/Instagram.

Что входит в установку (файл `docker-compose.yml`):

| Часть | Что делает |
|---|---|
| `app` | сама CRM: сайт, API, Telegram-бот, напоминания, утренняя сводка |
| `postgres` | база данных |
| `backup` | каждую ночь делает копию базы и файлов (фото, чеки), хранит 14 дней |
| `caddy` | принимает https-запросы и сам получает сертификат |

## 1. Что купить

1. **Сервер (VPS)**: Ubuntu 24.04, **2 ядра, 4 ГБ памяти, 40 ГБ диска** или больше. Обычно это $6–12 в месяц.
   Подойдёт любой провайдер, где проходит ваша карта: например, Hetzner, DigitalOcean, Vultr, Timeweb Cloud
   (у него есть дата-центр в Алматы, ближе к Бишкеку). Цены проверьте на сайте провайдера в день покупки.
   После покупки у вас будет **IP-адрес** сервера и пароль (или SSH-ключ) для пользователя `root`.
2. **Домен**: например `lunagarden.kg` у регистратора домена .kg, или любой другой домен. Для CRM удобно взять
   поддомен `crm.` у вашего домена.

## 2. Направьте домен на сервер

В панели регистратора домена добавьте DNS-запись:

| Тип | Имя | Значение |
|---|---|---|
| A | `crm` | IP-адрес сервера |

Запись начинает работать от нескольких минут до нескольких часов. Проверить можно командой `ping crm.lunagarden.kg`:
она должна показывать IP сервера.

## 3. Подготовьте сервер

Подключитесь к серверу (на Windows — через PowerShell, на Mac — через Терминал):

```bash
ssh root@IP-СЕРВЕРА
```

Установите Docker:

```bash
curl -fsSL https://get.docker.com | sh
```

Если у сервера меньше 4 ГБ памяти, добавьте файл подкачки, иначе сборка может не уместиться:

```bash
fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile && echo '/swapfile none swap sw 0 0' >> /etc/fstab
```

Откройте только нужные порты (SSH, http, https):

```bash
ufw allow OpenSSH && ufw allow 80 && ufw allow 443 && ufw --force enable
```

## 4. Скачайте CRM

```bash
git clone https://github.com/bxbyarchi/bxbyarchilunagarden.git /opt/luna && cd /opt/luna
```

Репозиторий приватный, поэтому GitHub спросит логин и токен. Токен создаётся на github.com → Settings →
Developer settings → Personal access tokens (право на чтение репозитория).

## 5. Заполните настройки

```bash
cp .env.example .env && nano .env
```

Обязательно заполните:

| Ключ | Что вписать |
|---|---|
| `DOMAIN` | ваш адрес без https, например `crm.lunagarden.kg` |
| `POSTGRES_PASSWORD` | длинный случайный пароль базы. Его можно получить командой `openssl rand -hex 24` |

Остальное можно вписать сразу или позже, когда будет готово:

| Ключ | Для чего |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Telegram-бот (токен от @BotFather) |
| `ANTHROPIC_API_KEY` | ИИ: агент для гостей и ИИ-советник (сильные модели Claude) |
| `OPENROUTER_API_KEY` | бесплатные модели для ИИ-советника |
| `META_…`, `WHATSAPP_…`, `INSTAGRAM_…` | WhatsApp и Instagram, см. `docs/META.md` |

`PUBLIC_URL` и `DATABASE_URL` вписывать не нужно: установка сама собирает их из `DOMAIN` и `POSTGRES_PASSWORD`.

Сохраните файл: `Ctrl+O`, `Enter`, `Ctrl+X`. Ключи храните только в этом файле на сервере и не присылайте в чат.

## 6. Запустите

```bash
docker compose up -d --build
```

Первая сборка занимает 5–10 минут. Проверка, что всё запущено:

```bash
docker compose ps
```

У `app` и `postgres` должно быть `healthy`. Откройте в браузере `https://crm.lunagarden.kg`. При первом входе CRM
предложит создать **главного администратора**: придумайте логин и надёжный пароль.

Если сайт не открывается:

```bash
docker compose logs caddy --tail 30
docker compose logs app --tail 50
```

Чаще всего причина в том, что DNS-запись из шага 2 ещё не начала работать. Caddy будет пробовать снова сам,
перезапускать ничего не нужно.

## 7. Обновление CRM

Когда в репозитории появятся новые функции:

```bash
cd /opt/luna && git pull && docker compose up -d --build
```

База данных обновляется при запуске сама. Данные, фото и копии при обновлении сохраняются.

После изменения `.env` (например, добавили ключ) достаточно перезапустить приложение:

```bash
docker compose up -d app
```

## 8. Резервные копии

Копии лежат на сервере в папке `/opt/luna/backups`. Состояние копий видно в CRM: «Настройки → Копии». Если копия
не делалась больше суток, администраторам придёт сообщение в Telegram.

Копия на том же сервере не спасёт, если пропадёт сам сервер. Поэтому раз в неделю скачивайте свежие файлы
к себе (или включите у провайдера платные снимки сервера):

```bash
scp root@IP-СЕРВЕРА:/opt/luna/backups/*.dump root@IP-СЕРВЕРА:/opt/luna/backups/*.tgz .
```

Как восстановить данные из копии, описано в `docs/BACKUP.md`.

## Полезные команды

| Что нужно | Команда |
|---|---|
| посмотреть, что работает | `docker compose ps` |
| журнал приложения | `docker compose logs app --tail 100` |
| перезапустить CRM | `docker compose restart app` |
| остановить всё | `docker compose down` (данные сохраняются) |
| сделать копию прямо сейчас | `docker compose run --rm -e RUN_ONCE=1 backup` |
