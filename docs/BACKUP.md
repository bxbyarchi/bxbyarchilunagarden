# Резервные копии и восстановление

## Что копируется и когда

Сервис `backup` из `docker-compose.yml` каждую ночь в **04:00 по Бишкеку** (меняется переменной `BACKUP_HOUR`)
кладёт в папку `backups/` рядом с `docker-compose.yml`:

| Файл | Что внутри |
|---|---|
| `db-ГГГГ-ММ-ДД_ЧЧММ.dump` | вся база: склад, продажи, брони, сотрудники, задачи, деньги, база знаний… |
| `files-ГГГГ-ММ-ДД_ЧЧММ.tgz` | файлы сервера: фото отметок прихода/ухода, фото чеков и счетов |
| `last-backup.txt` | время последней удачной копии |

Хранятся копии за **14 дней** (`BACKUP_KEEP_DAYS`). При первом запуске копия делается сразу.

Статус видно в CRM: **Настройки → Копии** (только владелец). Если копий нет больше 36 часов, владельцу
приходит предупреждение в Telegram.

**Важно:** копии лежат на том же сервере. Раз в неделю переносите папку `backups/` на флешку или в облако —
иначе при поломке диска пропадут и данные, и копии.

## Проверить, что копирование работает

```bash
docker compose logs --tail=20 backup
```

```bash
ls -lh backups/
```

## Восстановить базу из копии

1. Остановите приложение (база продолжает работать):

```bash
docker compose stop app
```

2. Пересоздайте базу и загрузите копию (подставьте нужный файл):

```bash
docker compose exec -T postgres sh -c 'dropdb -U "$POSTGRES_USER" "$POSTGRES_DB" && createdb -U "$POSTGRES_USER" "$POSTGRES_DB"'
```

```bash
docker compose exec -T postgres sh -c 'pg_restore -U "$POSTGRES_USER" -d "$POSTGRES_DB" --no-owner' < backups/db-2026-11-18_0400.dump
```

3. Верните файлы (фото), если нужно:

```bash
docker compose run --rm -v "$PWD/backups:/backups" --entrypoint sh backup -c 'cd /data && tar -xzf /backups/files-2026-11-18_0400.tgz'
```

Для этой команды временно уберите `:ro` у строки `app-data:/data:ro` в сервисе `backup`.

4. Запустите приложение:

```bash
docker compose start app
```

## Работа без интернета

CRM работает в сети ресторана и без интернета. Без связи не работают только внешние вещи:

- **Telegram:** уведомления не теряются, а копятся в очереди и уходят, когда связь вернётся,
  с пометкой «отправлено с задержкой». Хранятся до 48 часов.
- **ИИ-агент и ИИ-советник:** без интернета не отвечают. Агент вежливо отвечает гостям, что передал вопрос
  менеджеру, и помечает диалог как важный.
