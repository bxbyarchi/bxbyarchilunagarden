# Подключение WhatsApp и Instagram (Meta)

CRM получает сообщения гостей через официальные API Meta. ИИ отвечает сразу. Ответы менеджера из CRM уходят
гостю в тот же мессенджер. С гостями всегда работает сильная модель Claude.

Что нужно заранее:

- CRM работает на сервере с адресом **https://…**, например `https://crm.lunagarden.kg` (установка — `docs/DEPLOY.md`). Без https Meta не подключит вебхук.
- Номер телефона для WhatsApp (см. «Важно про номер»).
- Instagram-аккаунт ресторана, переведённый в **профессиональный** (Бизнес или Автор).

## 1. Бизнес-портфолио и приложение Meta

1. Зайдите на business.facebook.com и создайте **бизнес-портфолио** «Luna Garden».
   Позже пройдите **подтверждение компании**: нужны документы ИП/ОсОО. Оно снимает лимиты на число диалогов в WhatsApp.
2. Зайдите на developers.facebook.com → **My Apps → Create App** → тип **Business**, привяжите портфолио.
3. В приложении: **App settings → Basic** → скопируйте **App Secret**. Это `META_APP_SECRET`.
4. Придумайте любое слово-пароль для вебхука, например `luna-garden-2026`. Это `META_VERIFY_TOKEN`.

## 2. WhatsApp

1. В приложении нажмите **Add product → WhatsApp → Set up**.
2. **API Setup → Add phone number**: введите номер ресторана и отображаемое имя «Luna Garden», подтвердите номер кодом из SMS или звонка.
3. Скопируйте **Phone number ID**. Это не сам номер, а его id. Это `WHATSAPP_PHONE_NUMBER_ID`.
4. Постоянный токен: **Business settings → Users → System users → Add** (роль Admin) → **Assign assets** (ваше приложение
   и WhatsApp-аккаунт, полный доступ) → **Generate token** с правами `whatsapp_business_messaging` и
   `whatsapp_business_management`, срок «Никогда». Это `WHATSAPP_TOKEN`.
5. **WhatsApp → Configuration → Webhook → Edit**:
   - Callback URL — адрес из CRM: «ИИ-агент → Настройки агента → Каналы», вида `https://…/api/channels/meta/webhook`;
   - Verify token — ваш `META_VERIFY_TOKEN`;
   - затем **Manage** → подпишитесь на поле **messages**.

### Важно про номер

- Номер, подключённый к API, как правило **перестаёт работать в обычном приложении WhatsApp**. Лучше взять отдельный
  номер для ресторана или проверить в Meta, доступен ли для вашего номера режим совместной работы с приложением
  WhatsApp Business (coexistence).
- WhatsApp разрешает свободно писать гостю **в течение 24 часов после его последнего сообщения**. Позже — только
  одобренными шаблонами. CRM покажет понятную ошибку, если окно закрыто. Тогда позвоните гостю или дождитесь,
  пока он напишет.
- Диалоги, которые начинает гость, сейчас бесплатны. Платные — только шаблонные рассылки от ресторана.

## 3. Instagram

1. В приложении нажмите **Add product → Instagram → API setup with Instagram login**.
2. **Generate access tokens → Add account**: войдите в Instagram ресторана и разрешите доступ к сообщениям.
   Скопируйте токен (`INSTAGRAM_TOKEN`) и id аккаунта (`INSTAGRAM_ACCOUNT_ID`).
3. **Configure webhooks**: тот же Callback URL и Verify token, что для WhatsApp. Подпишитесь на поле **messages**.
4. В самом Instagram: **Настройки → Сообщения и ответы на истории → Инструменты для сообщений → Подключённые инструменты**
   → разрешите доступ к сообщениям.
5. Пока приложение в режиме разработки, сообщения приходят только от людей, добавленных в приложение как тестировщики.
   Чтобы отвечали всем гостям, нужна **проверка приложения (App Review)** с правом `instagram_business_manage_messages`:
   короткое видео, как работает ответ в CRM. Его подготовим вместе.
6. Instagram разрешает отвечать в течение **7 дней** после сообщения гостя.

## 4. Ключи на сервере

Впишите в файл `.env` на сервере. Не присылайте ключи в чат. Адрес сайта берётся из `DOMAIN`
(см. `docs/DEPLOY.md`).

```
META_APP_SECRET=…
META_VERIFY_TOKEN=…
WHATSAPP_TOKEN=…
WHATSAPP_PHONE_NUMBER_ID=…
INSTAGRAM_TOKEN=…
INSTAGRAM_ACCOUNT_ID=…
```

Перезапустите приложение:

```bash
docker compose up -d app
```

## 5. Проверка

1. В CRM откройте «ИИ-агент → Настройки агента → Каналы»: оба канала должны быть «подключены».
2. Напишите ресторану в WhatsApp и в Instagram с личного телефона. ИИ ответит, диалог появится в «ИИ-агент → Диалоги».
3. Нажмите «Взять диалог» и ответьте из CRM — сообщение придёт вам в мессенджер.
4. Если менеджер ответит прямо из приложения Instagram, CRM это увидит, и ИИ перестанет вмешиваться в этот диалог.

Голосовые, фото и стикеры ИИ пока не разбирает: он вежливо попросит написать текстом или позовёт менеджера.
